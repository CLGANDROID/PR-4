# Simple Calc

Android-додаток «Простий калькулятор», реалізований на Jetpack Compose. Користувач вводить два числа й натискає одну з чотирьох кнопок арифметичних операцій — результат одразу відображається на екрані.

## Операції

| Кнопка | Операція | Примітка |
|---|---|---|
| `+` | Додавання | |
| `-` | Віднімання | |
| `x` | Множення | |
| `/` | Ділення | При діленні на нуль виводиться повідомлення про помилку |

Якщо одне з полів порожнє або містить некоректне значення, замість результату виводиться повідомлення «Введіть два числа».

## Реалізація

- **Головний екран.** `MainActivity` створює інтерфейс через `setContent`, основний контейнер — `Scaffold`, всередині якого викликається composable-функція `SimpleCalcApp`. Елементи розміщені у `Column`.
- **Керування станом.** Значення двох полів і результат зберігаються у `remember { mutableStateOf(...) }` (`number1`, `number2`, `result`). Значення змінюються через `onValueChange`.
- **Перетворення введення.** Текст перетворюється на число функцією `toDoubleOrNull()`, що дозволяє перевірити коректність введених даних.
- **Обробка натискання кнопок.** Для кожної операції створено окрему `Button`. Параметр `onClick` виконує відповідну арифметичну операцію та записує результат у стан `result`, після чого Compose автоматично оновлює `Text` з результатом.
- **Ділення на нуль.** Перед діленням перевіряється, що друге число не дорівнює нулю.
- **Клавіатура.** Для полів введення задано `KeyboardType.Number` та `ImeAction.Done`. Клавіатура закривається кнопкою «Готово», дотиком поза полем введення та натисканням кнопки операції через `LocalFocusManager`. Завдяки `imePadding()` і `verticalScroll` клавіатура не перекриває результат.
- **Вигляд кнопок.** Кнопки мають `RoundedCornerShape(8.dp)`, символи операцій — розмір `24.sp`.
- **Передперегляд.** Для перевірки інтерфейсу створено функцію `GreetingPreview` з анотаціями `@Preview` та `@Composable`.

## Технології

- Kotlin
- Jetpack Compose (Material 3)
- Android Studio

## Структура проєкту

```
app/src/main/java/com/example/simplecalc/MainActivity.kt
app/src/main/java/com/example/simplecalc/ui/theme/   # кольори, тема, типографіка
```

## Запуск

1. Відкрити проєкт у Android Studio.
2. Дочекатися синхронізації Gradle.
3. Запустити конфігурацію `app` на емуляторі або фізичному пристрої.
